Challenge 2

  1. Can you name the nine HTTP request methods?
    1. GET - fetches a resource from the server - body, + safe, + idempotent
    2. POST - creates a new resource associated with the URI, or performs some other operation using the data provided by the client + body, - safe, - idempotent
    3. PUT - updates (or creates) the resource associated with the URI + body, - safe, + idempotent
    4. DELETE - deletes the resource associated with the URI + body, - safe, + idempotent
    5. PATCH - updates the resource using the data provided in the body of rthe request + body, - safe, - idempotent
    6. OPTIONS - returns the "communications options" (gen. methods) available for the resource (not always supported) - body, + safe, + idempotent
    7. HEAD - returns the headers that would accompany the resource without the content (gets metadata) - body, + safe, + idempotent
    8. TRACE - debugging method that provides information on the servers that process the request and response - body, + safe, + idempotent
    9. CONNECT - establishes a connection to the resource / server not REST
  2. Pick three and describe what these request types do? See GET, POST, PUT above
  3. Which request only retrieves data from a server? GET

In your groups identify how a cloud platform uses

  1. IP Addresses used by programs to identify hosts and thus to communicate with servers; IP addresses are frequently obtained by translating from host names using calls to library functions, which may either translate explicitly from a name to an address or make use of such a call in creating a channel through which data may be exchanged with a server.
  2. URI & URL A URI (uniform resource identifier) provides a way of specifying a resource on the internet. URIs are divided into URLs (uniform resource locations), which specify how to access a resource, and URNs (uniform resource names), which provide a unique identifier that can continue to be used to refer to the resource regardless of where (or if) it can be accessed at a particular point in time.
  3. DNS a domain name server translates between the name of a host and the associated IP address(es); host names have advantages when it comes to storing locations and interacting with users, while the internet protocol (the IP in TCP/IP) makes use of numeric IP addresses.
Are they different to traditional servers?
The term "cloud platform" basically refers to a network of servers that provide access to computing resources to clients. This includes storage, processing, and access to software resources.
